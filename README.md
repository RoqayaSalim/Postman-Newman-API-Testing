# Postman & Newman API Testing – TMDB

Automated API testing project for **The Movie Database (TMDB) API**, developed using **Postman** and executed through **Newman** with detailed HTML test reports.

The project demonstrates API test automation, authentication, positive and negative testing, JavaScript assertions, environment variables, and command-line test execution.

## 📁 Repository Structure

* **The_Movie_Database_Api.postman_collection.json**
  Postman collection containing API requests, test scenarios, and JavaScript test scripts.

* **TMDB_API.postman_environment.json**
  Postman environment containing configurable variables required to execute the collection.

* **bug-report.html**
  HTML test execution report generated by Newman using the `htmlextra` reporter.

## 🛠️ Technologies & Tools

* **Postman** – API request creation, test scripting, and collection execution.
* **Newman** – Command-line runner for executing Postman collections and supporting automation/CI workflows.
* **JavaScript** – Used to write API test scripts and assertions.
* **Newman HTML Extra Reporter** – Generates detailed and interactive HTML test reports.
* **Git & GitHub** – Version control and project documentation.

## 🔐 Environment Variables

Environment variables are used to manage configurable and sensitive values without hardcoding them into the collection.

The project uses:

* `baseUrl`
* `apiKey`
* `bearerToken`

### Security

No real API keys, Bearer tokens, passwords, or other sensitive credentials are stored in this repository.

Before running the tests locally, provide your own valid credentials in the Postman environment.

## ▶️ Running the Tests

### Prerequisites

Make sure the following are installed:

* Node.js
* Newman
* Newman HTML Extra Reporter

You can install Newman and the HTML reporter using npm:

```bash
npm install -g newman
npm install -g newman-reporter-htmlextra
```

### 1. Run Using Postman

1. Clone the repository.
2. Open Postman.
3. Import `The_Movie_Database_Api.postman_collection.json`.
4. Import `TMDB_API.postman_environment.json`.
5. Add your own API credentials and required environment values.
6. Select the imported environment.
7. Open the Collection Runner.
8. Run the collection and review the test results.

### 2. Run Using Newman

From the repository directory, execute:

```bash
newman run The_Movie_Database_Api.postman_collection.json -e TMDB_API.postman_environment.json -r htmlextra --reporter-htmlextra-export bug-report.html
```

After execution, Newman generates an HTML report named:

`bug-report.html`
