# Postman & Newman API Testing – TMDB

Automated API testing project for **The Movie Database (TMDB) API**, developed using **Postman** and executed through **Newman**. The project is integrated with **Jenkins** to automate test execution through a CI pipeline and generate detailed HTML test reports.

The project demonstrates API test automation, authentication, positive and negative testing, JavaScript assertions, environment variables, command-line test execution, and Continuous Integration.

---

## 📁 Repository Structure

* **The_Movie_Database_Api.postman_collection.json**
  Postman collection containing API requests, test scenarios, and JavaScript test scripts.

* **TMDB_API.postman_environment.json**
  Postman environment containing configurable variables required to execute the collection.

* **bug-report.html**
  HTML test execution report generated by Newman using the `htmlextra` reporter.

## 🔄 CI Pipeline with Jenkins

The project is integrated with **Jenkins** to automate API test execution.

The Jenkins pipeline performs the following steps:

1. Retrieves the latest project version from the GitHub repository.
2. Executes the Postman collection using Newman.
3. Uses the configured environment variables during test execution.
4. Generates an HTML test execution report using the Newman HTML Extra Reporter.
5. Displays the build status and test execution results through Jenkins.

This integration demonstrates how API automated tests can be incorporated into a **Continuous Integration (CI) workflow**.

## ▶️ Running the Tests

### Prerequisites

Make sure the following are installed:

* Node.js
* Newman
* Newman HTML Extra Reporter

You can install Newman and the HTML reporter using npm:

```bash
npm install -g newman
npm install -g newman-reporter-htmlextra
```

### 1. Run Using Postman

1. Clone the repository.
2. Open Postman.
3. Import `The_Movie_Database_Api.postman_collection.json`.
4. Import `TMDB_API.postman_environment.json`.
5. Add your own API credentials and required environment values.
6. Select the imported environment.
7. Open the Collection Runner.
8. Run the collection and review the test results.

### 2. Run Using Newman

From the repository directory, execute:

```bash
newman run The_Movie_Database_Api.postman_collection.json -e TMDB_API.postman_environment.json -r htmlextra --reporter-htmlextra-export bug-report.html
```

After execution, Newman generates an HTML report named:

`bug-report.html`

### 3. Run Using Jenkins

The project can also be executed automatically through the configured Jenkins Pipeline.

The Jenkins pipeline is connected to this GitHub repository and automates the test execution process using Newman.

After triggering a build, Jenkins:

* Retrieves the project from GitHub.
* Executes the API test collection.
* Runs the tests using Newman.
* Generates the HTML test report.
* Displays the build execution status.
